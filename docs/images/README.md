# README artwork

These original SVG illustrations explain MedMinder's purpose, workflow and architecture. They are **not screenshots**, clinical diagrams or evidence of a deployed application. They contain no patient information, dates, credentials or real medication examples.

- `medminder-overview.svg`: project introduction and conceptual checklist.
- `medminder-workflow.svg`: plan → record → review.
- `medminder-architecture.svg`: local Android/Web stores and optional Firebase synchronization.

## Hebrew visual tour

- `medminder-user-journey-he.svg`: schedule → recorded intake → history, with no clinical examples.
- `medminder-reminders-he.svg`: event generation and Android scheduling, permission dependencies and the limited future-event horizon.
- `medminder-sync-privacy-he.svg`: local stores, optional cloud, pull/merge/push and the limits of encryption and sync completeness.

The Hebrew diagrams use right-to-left reading order, explicit text direction, high-contrast text and generous spacing. They were rendered with Inkscape and visually inspected. Each SVG has a descriptive title; README embeds also provide alternative text. The English guide retains the original three English illustrations.

All files are self-contained, use no scripts, reference no external assets and include no capture dates, genuine health records or credentials. These are documentation illustrations, never substitutes for real UI screenshots.
