# README artwork

These original SVG illustrations explain MedMinder's purpose, workflow and architecture. They are **not screenshots**, clinical diagrams or evidence of a deployed application. They contain no patient information, dates, credentials or real medication examples.

- `medminder-overview.svg`: project introduction and conceptual checklist.
- `medminder-workflow.svg`: plan → record → review.
- `medminder-architecture.svg`: local Android/Web stores and optional Firebase synchronization.

SVG text is intentionally English to remain readable across renderers; the main README includes a Hebrew introduction and accessible alternative text. Files are self-contained and reference no external assets.
